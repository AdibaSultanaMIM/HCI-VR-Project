# HCI-VR-Project
Virtual Reality-Based Interactive System for Enhanced Real Estate Exploration and Custom Interior Design
Traditional real estate visualization methods like 2D drawings and
static images often fail to help clients fully understand space and
design potential. Virtual Reality (VR) addresses this by offering
immersive, interactive experiences where users can explore and
customize virtual properties in real time. This study introduces a
VR system built with Unity 3D, XR Toolkit, and Blender, featuring
3D walkthroughs, real-time color changes, dynamic lighting and
weather, and drag-and-drop furniture adjustments. The development
followed a clear process: analyzing user needs, creating virtual
environments, integrating interactive features, and thorough testing
on VR headsets. Performance tests showed smooth, high-quality
visualization and intuitive interaction. This platform empowers architects,
real estate agents, and clients to communicate design ideas
effectively and make quicker, more informed decisions. By combining
immersive visualization with active customization, the system
enhances presence and supports sustainable design choices. It also
aligns with current trends in VR use for real estate, which highlight
improved buyer engagement, reduced decision times, and broader
market reach. Future improvements may include AI-based design
suggestions and collaborative features, expanding VR’s role from a
visualization tool to a comprehensive decision-making solution
